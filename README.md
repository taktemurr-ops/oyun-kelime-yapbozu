# Kelime Yapbozu · Word Pieces

Parçaları birleştir, kelimeleri kur!

Kelimeler iki üç harflik parçalara bölündü. Parçalara doğru sırayla dokunarak kelimeyi oluştur; bulunan kelime yukarıda açılır. Bütün parçaları kullan.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
